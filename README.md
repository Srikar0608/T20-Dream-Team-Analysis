# 🏏 T20 Dream Team Analysis

## 📌 Project Overview

The **T20 Dream Team Analysis** project aims to identify the best-performing cricket players and create an optimal Dream XI using data-driven insights. The analysis is performed using player batting and bowling statistics collected from T20 matches.

By leveraging **Python, SQL, Power BI, and Excel**, the project evaluates player performance through various key performance indicators (KPIs) such as runs scored, strike rate, wickets taken, economy rate, and consistency.

---

## 🎯 Objectives

* Analyze T20 cricket match data.
* Evaluate player performance using batting and bowling metrics.
* Identify top-performing players for each role.
* Build a data-driven Dream XI.
* Create interactive dashboards for visualization and decision-making.
